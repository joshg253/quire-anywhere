# Chrome Extension: Quire Anywhere

The source code for [Quire Anywhere](https://chrome.google.com/webstore/detail/quire-anywhere/nojpnnfpfaepolalpokjlblonedknfgf), a chrome extension that easily allows you to add tasks from around the web easily. 


Right-click a page or selected text and choose "Add links on this page/in selected text to Quire…" to open a dialog listing its links grouped by domain: tick whole domains or single links, choose whether each task is titled by link text or URL (remembered), and add them as one task each (cleaned URL and source page in the description; project per Site Rules/adapter sites). Domains owned by an enabled adapter have an "Enrich" checkbox (on by default): each of their links is opened in a background tab (3 at a time) and added like a page with the adapter's title, tags and fields (the title choice then doesn't apply); the browser asks once for permission to read those domains. Other links are plain tasks.

Settings has Site Rules: tasks added from a site (e.g. bandcamp.com) go to the project you choose instead of the default.

Settings has Site Adapters (off until enabled), grouped into collapsible categories (Music, Games). Each card collapses. Enabling one covers its sites (e.g. bandcamp.com) without a Site Rule: each starts on "Default" and can be given its own project, and you can add more sites. Each adapter also has a task title format (e.g. "{name} [{year}]") and Text (single-line) custom field rows (e.g. Year = "{year}", none by default). Bandcamp strips `ref` and `utm_*` tracking parameters from the URL and fills due date, estimate, priority, the year (if you add a field row for it) and tags (with your tag aliases, minus tags you ignore; Ignored Tags are chips sorted A-Z, and aliases are one row per your tag with its page texts separated by ";", filterable, and a location alias like "Los Angeles, California" never falls back to its parts; an alias's tag is created in the project if it doesn't exist yet, but page tags are never created); HowLongToBeat game pages set the title ("Game [year]") and Estimate (Main Story, Main + Extras, Completionist or All Styles). Steam app pages set the title ("Game [year]"), Estimate (HowLongToBeat time via Augmented Steam's API; Main Story, Main + Extras or Completionist) plus the HowLongToBeat link under the Steam URL in the description, the Steam tag (if the project has one) and the custom fields Platform = Windows and Own on = Steam (editable). Epic Games product pages set the title ("Game [year]", from Epic's content API), the Epic tag (if the project has one) and a HowLongToBeat search link under the Epic URL in the description (no Estimate: HowLongToBeat can't be searched by name). Spotify album and playlist pages set the title ("1:36 Artist – Album [year]"; a duration of 1 hr 36 min shows as 1:36, 42 min 10 sec as 42:10), due date (the release date, if the page shows it) and Estimate (the total length). A playlist is titled "Playlist – Name" (no year or due date; "Playlist" is a setting).

`tools/batch-enrich-bandcamp.mjs` is a standalone Node script (not part of the extension) that moves Bandcamp tasks from an inbox project into your Bandcamp project and enriches them like the extension does. It is a dry run unless given `--apply`; see the comments at the top of the file.
